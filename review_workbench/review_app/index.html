Count only numbered figures in the main paper—not SI figures. We use these counts to estimate what the text-only extractor misses by ignoring figures.

                

                  
                  
                  
                  
                

                
Figure-only means the record or atomic field value belongs in the schema but is not explicitly reported in the caption, running text, or a table. Count one numbered figure once, not each panel. Count field instances—not pixels or sampled points—and do not infer or digitize uncertain values.

It shows records you marked for correction, records added or revised during the model's second evidence read, and device families with an A/B/X assignment that did not pass every automated check.
